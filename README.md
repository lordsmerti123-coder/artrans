# BabelDuo (ARtrans)

Переводчик живого разговора. Двое собеседников говорят каждый на своём языке
в свою гарнитуру и слышат перевод друг друга в наушнике. Перевод идёт
в обе стороны одновременно, ждать очереди не нужно.

Языков шесть: русский, английский, французский, испанский, армянский
и китайский. Пара выбирается в интерфейсе отдельно для каждого собеседника.

Делал для живого общения, когда собеседник не говорит по-русски, а переводчик
рядом не нужен.

## Всё локально

Ни одного байта не уходит в интернет. Ради этого и выбирались модели.

Распознавание речи — GigaAM, перевод — GGUF-модель через llama.cpp, синтез —
Piper. Всё считается на своём компьютере.

На практике это значит: разговор не покидает комнату. Облачных сервисов
в схеме просто нет.

Интернет не нужен ни при запуске, ни во время разговора. Аккаунты, ключи
и подписки не требуются. Записывать разговор можно, но журнал текста
по умолчанию выключен настройкой `log_text`.

Это важно для разговоров, которые не должны попадать третьим лицам:
переговоров, приёма посетителей, работы с персональными данными. Обычные
онлайн-переводчики отправляют каждую фразу на чужой сервер — здесь этого
не происходит по устройству программы.

## Как устроено

Разговор идёт в две стороны сразу. По шагам для одной стороны:

1. **Слушаем.** Программа пишет с микрофона и ждёт, пока человек договорит.
   Детектор речи сам понимает, где конец фразы — нажимать ничего не нужно.

2. **Распознаём.** GigaAM превращает сказанное в текст.

3. **Проверяем язык.** Прежде чем переводить, программа убеждается, что текст
   на нужном языке. Это защита от шума, который распознался как слова,
   и от эха второго собеседника: если его голос попал в ваш микрофон,
   программа это заметит и не станет переводить вашу речь обратно.

4. **Переводим.** Локальная модель переводит текст. Есть два варианта:
   GGUF-модель (по умолчанию Llama-3.1-8B-Instruct) и NLLB-200 на 200 языков.
   Выбор в настройках.

5. **Говорим.** Piper синтезирует перевод и отправляет в наушники второго
   собеседника. Голоса для разных языков отдельные.

## Что работает

Живой разговор в две стороны — основной сценарий. Шесть языков, распознавание
и синтез на каждом из них.

Есть мастер сопряжения гарнитур, VU-метр для проверки звука до начала,
пресеты качества от быстрого до точного, шумоподавление по каналам отдельно,
журнал сессий.

Режим одного микрофона: если гарнитура только одна, программа по языку
определит, кто говорит, и направит перевод правильному собеседнику. Галочка
ручного режима языка в интерфейсе.

Bluetooth работает, но с задержками — об этом ниже.

В разработке перевод длинных речей и лекций. Сейчас программа рассчитана
на короткие реплики, предел задаётся в настройках и по умолчанию 20 секунд.
Для разговора хватает, для доклада мало.

## Про наушники

Bluetooth программа поддерживает, но качество разговора зависит от того,
как подключаются наушники.

Две Bluetooth-гарнитуры работают, но заметны паузы. Bluetooth и наушники
с донглом лучше — одна сторона идёт ровно. Две гарнитуры с передатчиком
или по проводу дают лучший результат: задержек нет.

Дело не в программе, а в Windows: Bluetooth-звук там обрабатывается
с задержкой и переключается между режимами «стерео» и «гарнитура».
В коде есть режим `bluetooth_mode`, он добавляет паузы и сглаживает это,
но полностью особенность не убирает.

Для пары нужны две гарнитуры, по одной на собеседника. Отдельная кнопка
«говорить» не нужна.

## Установка

Нужен Windows или Linux, Python 3.12 и около 6 ГБ под модели. Видеокарта
NVIDIA рекомендуется: распознавание и перевод на ней в разы быстрее,
но без неё тоже работает.

Окружение:

```powershell
python -m venv venv
venv\Scripts\activate
```

GigaAM для распознавания речи ставится отдельно:

```powershell
git clone https://github.com/salute-developers/GigaAM.git GigaAM
pip install -e ./GigaAM
```

Остальное:

```powershell
pip install -r requirements.txt
```

Для видеокарты PyTorch ставится под свою версию CUDA:

```powershell
pip install torch --index-url https://download.pytorch.org/whl/cu128
```

Чтобы перевод шёл на видеокарте:

```powershell
CMAKE_ARGS="-DGGML_CUDA=on" pip install llama-cpp-python --force-reinstall --no-cache-dir
```

Веса моделей в репозитории не лежат, они тяжёлые. Что скачать и куда положить —
в [models/README.md](models/README.md). Коротко структура такая:

```
models/
├── asr/multilingual_ctc.ckpt      GigaAM, распознавание речи
├── translate/nllb/                модель перевода
└── tts/piper/ru/voice.onnx        голоса для синтеза
```

## Языки

Пара выбирается прямо в интерфейсе. У каждого собеседника два списка:
«Говорит» и «→», то есть язык собеседника и язык перевода. Выбор сразу
сохраняется в `config.json`.

Доступны `ru`, `en`, `fr`, `es`, `hy`, `zh`. По умолчанию стоит пара
«русский — английский» в обе стороны. Можно поставить любую другую, голос
синтеза подберётся по языку перевода автоматически.
